# YTV2 一覧生成ツール

名前やチャンネルなどの情報を登録しておき、**名前をクリックして選ぶだけ**で「名前＋各種リンク」の一覧テキストを生成できる Windows デスクトップアプリです。

配信の参加者一覧やコラボ相手のリンクまとめなど、「名前とリンクのリスト」を毎回作る作業を楽にします。

- 現在のバージョン：**v2.8.2**
- 対応OS：Windows（インストーラー版）／ブラウザ版も同梱

---

## ダウンロード方法

1. このリポジトリの **[Releases](https://github.com/yorukaze-luru/YTV2/releases)** を開き、最新版（Latest）を選ぶ
2. **YTV2-Setup-x.y.z.exe** をダウンロードする
3. ダウンロードした exe を実行して、画面の案内に沿ってインストールする
   - 初回は Windows の警告（SmartScreen）が出ることがあります。その場合は「詳細情報」→「実行」の順に押してください（※署名なしで配布しているため表示されるもので、異常ではありません）
4. インストール後は、スタートメニューまたはデスクトップの「YTV2 一覧生成ツール」から起動できます

### アップデート方法

アプリが自動でお知らせします。画面の上に「新しいバージョンがあります」と表示されたら、**「アップデートをする」ボタンを押すだけ**です。

- ダウンロードの進捗がゲージで表示されます
- 完了すると自動でインストールされ、アプリが再起動します（セットアップ画面は出ません）。インストール中は進捗ウィンドウ（ゲージ）が表示されます
- 再起動後、最初にアップデート内容が別ウィンドウで表示されます
- 登録したデータはそのまま引き継がれます

## 使い方

### 基本の流れ

1. **登録する**：左の「登録ライブラリ」で「＋ 新規登録」を押し、名前・リンク・タグ・メモを入れる
2. **選ぶ**：ライブラリで名前をクリックすると、真ん中の「作成リスト」に入る（もう一度押す・✕で取り消し、ドラッグや↑↓で並び替え）
3. **使う**：右の「生成・出力」に一覧テキストが自動で表示されるので、「📋 コピー」または「💾 .txtで保存」

※「生成する」ボタンはありません。選んだり設定を変えたりすると、プレビューはその場で自動更新されます。

### 画面の見方（3つのエリア）

| エリア | 役割 |
| --- | --- |
| 📚 登録ライブラリ（左） | 登録した相手の一覧。検索・タグでの絞り込み、✏️から編集 |
| 🗂️ 作成リスト（真ん中） | 今回の一覧に入れる相手。並び順がそのまま出力順になります |
| ✨ 生成・出力（右） | テンプレートやオプションの選択と、生成結果のプレビュー・コピー・保存 |

### 便利な機能

- **リンクは自由に追加可能**：YouTube / X のほか、Twitch・TikTok・Instagram・ニコニコ動画・Discord・Bluesky・Webサイト・メールなどのプリセット＋自由ラベル。1人に何件でも登録でき、順番もドラッグや↑↓で変えられます
- **生成テンプレート**：標準／コンパクト／番号付き／名前のみ／告知用（◆付き・メモあり）から選択。番号・ラベル・メモの表示、区切り（空行／なし／線）、含めるリンクの種類もオプションで調整できます
- **ヘッダー／フッター**：プレビューの上下のボックスに入力すると、コピー・保存時に本文と合体します
- **検索・絞り込み**：名前／タグ／メモ／リンクを横断検索。タグはチップで複数選択、お気に入り（★）だけの表示や並び替えも可能。表示中の一括追加もあります
- **共有コード**：作成リストの内容を1つの文字列コードにして渡せます。受け取った側はライブラリ下の「🔗 共有コードで追加」に貼るだけ。新規の名前はそのまま追加され、すでにある名前にはタグとリンクだけが足されます（メモやお気に入りは上書きされません）
- **書き出し／取り込み**：「📤 書き出し」から JSON / CSV で保存、「📥 取り込み」で読み込み。バックアップや PC 間の引っ越しに使えます
- **ダークモード**：右上の 🌙 ボタンで切り替え

## データの保存場所

- 登録データは自動保存されます：`%APPDATA%\ytv2-desktop\ytv2-data.json`
- アプリを更新・再インストールしてもデータは消えません
- 心配なときは「📤 書き出し」で JSON を保存しておくと安心です

<details>
<summary><strong>ブラウザ版について（インストール不要）</strong></summary>

各リリースには、ブラウザ版の zip（`YTV2-Browser-*.zip`）も添付されています。

- ダウンロードして解凍し、中の `index.html` をブラウザで開くだけで使えます
- 機能はデスクトップ版と同じですが、違いが2つあります
  - データの保存先がブラウザの localStorage（ブラウザのデータを消すと消えるので注意）
  - 自動アップデートはありません（新しい zip を取り直してください）

</details>

<details>
<summary><strong>v1（旧 Web 版）について</strong></summary>

リポジトリ直下の `index.html` / `edit.html` / `tools/` は v1（Web 版）のファイルで、互換のため残しています。現在の正式版はこのデスクトップ版（v2）です。

- v1 の CSV（name,youtube,x,tags,favorite）や、v1 の保存データ（userData 形式の JSON）は、v2 の「📥 取り込み」でそのまま読み込めます（自動で変換され、名前で照合してマージされます）

</details>
