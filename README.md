# YTV2 - 一覧生成ツール（デスクトップ版 / v2.0.2）

名前やチャンネルなどの情報を先に登録しておき、名前をクリックして選ぶだけで、
名前＋各種リンクの一覧テキストを生成できる Windows デスクトップアプリです。

v1（Web版）から全面リニューアルしました。

## ■ v1からの主な変更

- **Windowsアプリ化（インストーラー版）**：Electron製。インストールするとスタートメニュー／デスクトップから起動でき、アンインストールはWindowsの設定から行えます
- **3ペイン構成に統合**：左「登録ライブラリ」／中央「作成リスト」／右「生成・出力」を1画面に。ページ移動なしで最後まで完結
- **様々に対応する登録形式**：リンクは YouTube / X 固定ではなく、Twitch・TikTok・Instagram・ニコニコ・Discord・Bluesky・Webサイト・メールなどプリセット＋自由ラベルで何件でも追加可能。メモ欄も追加
- **クリックで追加、ドラッグで並び替え**：ライブラリで名前をクリックすると作成リストへ。順序はドラッグ＆ドロップや↑↓で変更可能
- **生成テンプレート**：標準／コンパクト／番号付き／名前のみ／告知用（◆付き・メモあり）＋番号・ラベル・メモ・区切り（空行／なし／線）・ヘッダー／フッター・含めるリンクの種類を個別に調整可能。選ぶと出力は自動でプレビュー更新
- **検索・絞り込み強化**：名前／タグ／メモ／リンクを横断検索、タグはチップで複数選択、お気に入り優先などの並び順、表示中の一括追加
- **データ保存の改善**：ブラウザの localStorage ではなく、OSのユーザーデータフォルダ内のJSONファイルに自動保存（原子的に書き換え）。アプリを更新・再インストールしても消えません
- **CSVの不具合修正**：v1の単純なカンマ分割を廃止し、引用符・カンマ・改行を含む項目でも崩れない正しいCSV処理（RFC 4180）に変更
- **自動アップデート**：起動時にGitHubの最新リリースを確認し、新版があれば裏でダウンロード。完了したら「再起動して更新」を案内し、後回しにしてもアプリ終了時に自動で適用されます（electron-updater方式）
- **ダークモード対応**：🌙ボタンで切替。文字色は両テーマとも明示指定
- **旧データ移行**：v1のCSV（name,youtube,x,tags,favorite）と v1のJSON（userData形式）を取り込み時に自動変換。取り込みは名前で照合し、追加／更新としてマージされます

## ■ Web版（v1）について

リポジトリ直下の `index.html` / `edit.html` / `tools/script.js` などは v1（Web版）のファイルで、互換のため残しています。
現在の正式版はこのデスクトップ版（v2）です。旧データは取り込み機能でそのまま移行できます。

## ■ 使い方

1. 「＋ 新規登録」で名前・リンク・タグ・メモを登録
2. ライブラリで名前をクリックして作成リストに追加（並び替え・取り消し可）
3. テンプレートとオプションを選んで「生成する」
4. 「コピー」または「.txtで保存」

## ■ データの場所

- Windows: `%APPDATA%\ytv2-desktop\ytv2-data.json`
- バックアップは「📤 書き出し」→ JSON / CSV でいつでも取得できます

## ■ 開発・ビルド

```bash
npm install
npm test     # コアロジックのテスト
npm start    # Electronで起動
npm run dist # NSISインストーラーを dist/ に生成（Windows環境）
```

タグ（`v*`）をpushすると GitHub Actions（windows-latest）がテスト＋インストーラー生成を行い、
リリースに `.exe` を添付します（`.github/workflows/build-windows.yml`）。
