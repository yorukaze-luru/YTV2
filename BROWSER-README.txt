YTV2 一覧生成ツール（ブラウザ版）
================================

■ 使い方
1. このフォルダ内の index.html をブラウザ（Chrome / Edge / Firefox / Safari）で開く
2. 「＋ 新規登録」で名前・リンク・タグ・メモを登録
3. ライブラリで名前をクリックして作成リストに追加
4. テンプレートを選んで「生成する」→「コピー」または「.txtで保存」

インストール不要・ネット接続不要で動作します。

■ デスクトップ版との違い
- データの保存先：このブラウザの localStorage（ブラウザ・開き方ごとに別保存になります）
  → 別の環境へ移すときは「📤 書き出し」で CSV / JSON バックアップをご利用ください
- バージョン表示はありますが、アップデートのお知らせ・自動更新はありません（新しい zip は GitHub の Releases から取得してください）
- 機能（登録・絞り込み・生成テンプレート・CSV入出力・ダークモード）はデスクトップ版と同じです

■ 旧バージョン（v1）のデータについて
- v1のCSV（name,youtube,x,tags,favorite）や v1のJSONは「📥 取り込み」で自動変換されます
